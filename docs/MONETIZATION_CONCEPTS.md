# Концепции монетизации Bridgik

Документ фиксирует отобранные продуктовые идеи монетизации для сервиса Bridgik без ущерба для ключевых преимуществ: отсутствия обязательной регистрации, мгновенности и прямого P2P без лимитов на размер файлов.

---

## Концепция 1: «Оставить в шлюзе» (Асинхронный мост / Drop & Go)

### Суть и проблема
Классический WebRTC P2P требует, чтобы оба устройства (отправитель и получатель) одновременно находились в сети с открытыми вкладками браузера. Если получатель спит, находится в пути или в другом часовом поясе, отправителю приходится держать ноутбук включенным.

### Как это устроено
1. **Базовый режим (онлайн P2P):** 100% бесплатный, безлимитный, не нагружает диски сервера.
2. **Опция «В шлюз на 24ч»:**
   - Файл шифруется прямо на стороне клиента (Web Crypto API, AES-GCM-256).
   - Ключ шифрования зашит только в секретную ссылку / PIN (Zero-Knowledge: сервер физически не может прочитать данные).
   - Зашифрованный блоб временно загружается на сервер.
   - Отправитель закрывает браузер и уходит.
   - Получатель открывает ссылку в удобное время, скачивает файл, после чего файл **моментально удаляется** с сервера (или по истечении 24 часов).

### Модель оплаты
- **1 бесплатный шлюз в неделю** для всех посетителей (тест-драйв ценности).
- **Разовая микрооплата:** 29–49 ₽ за разовый файл (СБП / карта / эквайринг в 1 клик).
- **Пакетные ключи:** например, «10 отложенных передач» по анонимному токену без логина.

## Концепция 2: Bridgik как Telegram Mini App (TMA)

### Суть и проблема
Telegram имеет строгие ограничения на файлы: лимит 2 ГБ (для Premium — 4 ГБ) и искусственное занижение скорости скачивания на больших объемах. При этом в Telegram уже решена главная проблема конверсии — там встроены нативные платежи **Telegram Stars** в один клик по биометрии (Face ID / отпечаток).

### Как это устроено
1. **Запуск внутри Telegram:**
   - Бот открывает Bridgik прямо во встроенном окне (Telegram WebApp).
   - Не требуется регистрация: Telegram ID служит анонимным безопасным идентификатором сессии.
2. **Обход лимитов Телеграма:**
   - Отправка файлов любого размера (10–50+ ГБ) напрямую между смартфонами и ПК через P2P-мост без сжатия и без ограничений мессенджера.
3. **Уведомления и шеринг:**
   - Ссылка на мост или комнату отправляется другу прямо в чат Telegram в одно касание.
   - Бот уведомляет отправителя о завершении скачивания.

### Модель оплаты
- Оплата через **Telegram Stars**: пользователи психологически легко тратят звёзды на микросервисы (15–30 Stars за операцию).
- Оплата «Шлюза» или дополнительных функций комнат без ввода банковских карт.

---

## Синергия обеих концепций
Комбинация Telegram Mini App + «Шлюз» создаёт завершённый цикл:
- Внутри Telegram пользователь нажимает «Передать файл через Bridgik».
- Если друг онлайн — файлы перелетают бесплатно через P2P.
- Если друг офлайн — за пару Stars файл кладётся в защищённый шлюз, а бот автоматически отправляет другу сообщение со ссылкой на скачивание.
